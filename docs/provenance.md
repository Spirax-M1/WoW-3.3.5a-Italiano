# Provenienza dei componenti

Manutentore del repository: Salvatore (Spirax-M1).

Questo nome non attribuisce automaticamente al manutentore tutti i testi, addon, font o asset inclusi. Il repository contiene QuestTradutor, WoWItaliano, file Lua di dati, font e archivi MPQ. La revisione degli installer non ha ricostruito la provenienza completa di questi componenti.

Prima di una nuova release occorre registrare per ciascun componente: origine, autore, versione, modifiche locali e termini di utilizzo/distribuzione. Non è stata aggiunta una licenza globale che potrebbe attribuire permessi non verificati. Nessun eseguibile completo del gioco è distribuito; il manifest descrive modifiche per offset.

Questa è una lista di lavoro sulla documentazione, non una conclusione sulla liceità o illecità dei materiali.
